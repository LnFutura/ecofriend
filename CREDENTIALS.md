## 📝 Примечания

1. **⚠️ Безопасность**: Эти данные предназначены ТОЛЬКО для разработки и тестирования!
2. **🔄 Смена паролей**: В продакшене обязательно измените все пароли на безопасные.
3. **🚀 Первый запуск**: Используйте учетные данные администратора для первого входа.
4. **🔗 URL для входа**: 
   - Frontend: http://localhost:8080
   - Backend API: http://localhost:3001/api

## 🛠️ Как использовать

### Вход через фронтенд:
1. Откройте http://localhost:8080
2. Нажмите "Войти"
3. Введите email или username и пароль
4. Нажмите "Войти"

### Вход через API (curl):
```bash
# Вход администратора
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@ecodrug.ru",
    "password": "admin123"
  }'

# Вы получите token, который нужно использовать для защищенных запросов
```

### Использование токена:
```bash
# Пример защищенного запроса
curl -X GET http://localhost:3001/api/auth/me \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

## 🎯 Тестовые сценарии по ролям

### Администратор может:
- ✅ Управлять всеми пользователями
- ✅ Модерировать весь контент
- ✅ Создавать/редактировать/удалять курсы
- ✅ Верифицировать организации
- ✅ Просматривать статистику

### Модератор может:
- ✅ Модерировать новости и события
- ✅ Одобрять пользовательский контент
- ✅ Просматривать жалобы
- ❌ НЕ может управлять пользователями

### Организация может:
- ✅ Создавать новости и события (с автоматической публикацией, если верифицирована)
- ✅ Управлять своим профилем организации
- ✅ Просматривать статистику своего контента
- ❌ НЕ может модерировать контент других

### Обычный пользователь может:
- ✅ Проходить курсы
- ✅ Создавать новости (требуется модерация)
- ✅ Регистрироваться на события
- ✅ Зарабатывать баллы и достижения
- ✅ Просматривать карту переработки
- ❌ НЕ может публиковать без модерации
