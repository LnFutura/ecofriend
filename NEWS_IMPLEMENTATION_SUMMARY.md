## 🚀 Как запустить

### 1. Приложение уже запускается
Flutter компилируется в фоновом режиме на порту 8080.

### 2. Заполнить БД новостями
```bash
cd backend
node scripts/seedNews.js
```

### 3. Открыть браузер
```
http://localhost:8080
```

### 4. Войти в аккаунт
Используйте существующий аккаунт или зарегистрируйте новый.

### 5. Перейти на вкладку "Новости"
Клик на розовую иконку мегафона в нижней навигации.
