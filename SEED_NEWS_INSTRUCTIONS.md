# Инструкция по заполнению новостей

## 🌱 Создание тестовых новостей

Для заполнения базы данных тестовыми новостями выполните:

```bash
cd backend
node scripts/seedNews.js
```

## 📊 Что создается

Скрипт создаст 8 тестовых новостей с:
- Заголовками на русском языке
- Реальными изображениями из Unsplash
- Тегами городов (Анапе, Москве, Владивостоке и т.д.)
- Разными категориями (news, research, guide, event_report)
- Статусом "approved" (одобрено)

## ⚠️ Важно

Скрипт проверяет наличие существующих новостей и НЕ создаст дубликаты.
Если хотите пересоздать новости, сначала удалите их из БД:

```bash
# MongoDB Shell
use ecodrug
db.news.deleteMany({})
```

## ✅ После запуска

Новости будут доступны в приложении на вкладке "Новости" (розовый экран).

## 🔧 Если скрипт не работает

Убедитесь что:
1. MongoDB запущена и доступна
2. В `.env` файле правильный `MONGO_URI`
3. Есть пользователь с ролью `admin` в базе
